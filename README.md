## 🚀 Имкониятҳои Асосӣ
1. **100% Кори Офлайн**: Маҳдудиятҳои барномаҳо ва веб ҳатто бе интернет фаъол мемонанд.
2. **Бастани Барномаҳо**: Маҳдудияти вақт барои TikTok, Instagram, PUBG, Roblox ва ғайра.
3. **Интернети Бехатар (Safe Web)**: Филтратсияи худкори сомонаҳои номатлуб ва зараровар.
4. **Пайвастшавии якқадама**: Пайваст кардани телефони кӯдак бо камера тавассути рамзи QR дар 30 сония.
5. **Ҳифзи пурраи маълумот**: Алгоритми AES-256 ва бидуни нигоҳдории маълумоти махфӣ дар тарафи сеюм.

## 🛠️ Роҳандозӣ ва Идоракунӣ (Production)

### Навсозии сайт ва бастаҳо:
```bash
python3 scripts/deploy_production.py
```

### Фаъолсозии сертификати расмии SSL (HTTPS) дар Nginx:
Дар сервер фармони зеринро иҷро намоед:
```bash
sudo bash /home/dev/munis/deploy/setup_https.sh
```
