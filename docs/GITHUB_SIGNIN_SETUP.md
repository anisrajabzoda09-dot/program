# Sign in with GitHub — танзим

Код дар сайт, сервер ва барнома тайёр аст. Тугмаи **«Идома бо GitHub»** худ ба худ пайдо мешавад, вақте ки 2 арзиши поён дар сервер гузошта шаванд. GitHub ройгон аст — ҳисоби Developer-и пулакӣ лозим нест.

## Дар GitHub (5 дақиқа)
1. github.com → аксатон (боло рост) → **Settings** → дар поён **Developer settings** → **OAuth Apps** → **New OAuth App**.
2. Пур кунед:
   - **Application name:** `NIGOH Family`
   - **Homepage URL:** `https://nigohfamily.qobus.tj`
   - **Authorization callback URL:** `https://nigohfamily.qobus.tj/auth/github/callback`
     (як суроға барои сайт ва барнома — дигар чизе илова накунед)
3. **Register application**.
4. **Client ID**-ро нусха кунед.
5. **Generate a new client secret** → **Client secret**-ро нусха кунед. ⚠️ GitHub онро танҳо як бор нишон медиҳад.

## Дар сервер
Ба `~/munis/.env` илова кунед ва серверро аз нав оғоз кунед:

```
GITHUB_CLIENT_ID=Ov23li...
GITHUB_CLIENT_SECRET=...
```

Ё ин ду арзишро ба ман фиристед — ман худам мегузорам ва месанҷам.

## Чӣ тавр кор мекунад
- **Сайт:** `/auth` → «Идома бо GitHub» → саҳифаи иҷозати GitHub → бозгашт ба сайт бо сессия.
- **Барнома:** барнома браузерро мекушояд, сервер воридшавиро анҷом медиҳад ва ба барнома «билети» яккаратаи 2-дақиқаӣ бармегардонад. Билет танҳо бо рамзи тасодуфие, ки худи барнома нигоҳ медорад, кор мекунад — пас агар касе онро дуздад, истифода карда наметавонад.
- Ҳисоб аз рӯи ID-и доимии GitHub пайваст мешавад. Бо ҳисоби мавҷуда танҳо аз рӯи почтаи **тасдиқшуда** пайваст мешавад; агар дар GitHub почтаи тасдиқшуда набошад, воридшавӣ рад мешавад.
